# 发布方式

源码和运行环境分开发布。`setup/prepare_open_source.py --archive` 生成干净源码、Windows 文件夹、ZIP 分卷和校验清单。开发者本机需准备完整依赖、模型与 Electron，并调整脚本中的 Electron 路径。

`setup/publish_github.py --upload` 使用 Git credential helper 已保存的 GitHub 凭据在内存中调用 GitHub；不打印或写入令牌。首次创建公开仓库、推送源码、建立草稿 Release，附件全部上传后发布。仓库归属固定校验为 `1213109176kgy-png`，不覆盖其他仓库。

公开包默认使用小爱、预设音色与本地模式。清除凭据、个人设置、参考录音、聊天日志和测试对照视频；不附带 Wav2Lip256 或 MuseTalk 权重。

大于 GitHub 单附件限制的 ZIP 拆为小于 2GB 的分卷。每卷和合并 ZIP 均记录 SHA256，合并脚本验证分卷哈希再输出 ZIP。
