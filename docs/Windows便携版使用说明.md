# 数字人工作台 · Windows 便携版

GitHub 发布版：下载全部 `.zip.001` 等分卷、`合并整合包.cmd`、`Merge-Package.ps1` 和 `release-manifest.json`，放在同一文件夹，双击“合并整合包.cmd”，校验并合并后解压 ZIP。

首次启动会提示导入 Wav2Lip256 权重。公开包未附带授权不明确的口型权重，请按启动窗口的官方说明获取并选择对应 `.pth` 文件。已附带本地对话、语音识别、预设音色和参考录音克隆模型；无需另外安装 Python。

控制台点击“视频通话”会连接画面并申请麦克风权限，显示 3 秒拨打动画后开始对话。挂断同时关闭麦克风；画面右上角可切换全屏。

解压完整文件夹，双击 **数字人工作台.exe**。请不要只移动 EXE，模型、Python、CUDA 和界面都在旁边的文件夹里。

支持 Windows 10/11 64 位。无需安装 Python、Node、CUDA Toolkit 或 WSL；本地 Qwen3-TTS/Wav2Lip 仍需要 NVIDIA 显卡驱动和足够显存。本机验证配置为 RTX 4060 Laptop 8GB、16GB 内存。启动后模型需要加载和预热，等顶部服务就绪后点“连接数字人”。

## 三个菜单

- **控制台**：实时画面、聊天记录、文字发送、麦克风、打断和清空对话。未连接时显示底片预览，连接后显示真实视频流。身体动作由人物底片提供，Wav2Lip 按声音改变嘴部。
- **数字人配置**：切换形象，添加 1–30 秒单人正面视频，自动转 25 帧并检测人脸；选择预设音色，导入克隆参考录音，编辑角色名和提示词，设置记忆长度、回答长度、收音阈值及停顿时间。
- **模型配置**：选择本地/在线 LLM、ASR、TTS，导入本地权重，填写接口和密钥，测试连接。口型引擎当前为内置 Wav2Lip256。ComfyUI/Wan2.2 是可选外部底片制作工具，未内置巨型权重。

保存配置后，若提示需要重启，点右上角 **重启服务**。切换形象只需重新连接画面。关闭工作台会停止由该窗口启动的服务。

## 添加人物底片

在“数字人配置”点 **添加人物底片**，选择 MP4/MOV/MKV/AVI 视频。建议嘴巴闭合、固定镜头、自然呼吸眨眼；避免大幅转头、遮挡、多张人脸。处理会在后台进行，成功后出现新形象卡片，选择并保存即可。画面的大幅动作需要相应视频素材，调口型模型不会凭空产生全身动作。

## 在线模型和音色克隆

DeepSeek/豆包快捷配置仅设置兼容的对话端点；需填自己的 API Key 和模型/接入点 ID。ASR/TTS 的在线接口分别需要支持 `/audio/transcriptions`、`/audio/speech`，专有接口不能仅凭服务商名字自动通用。

Windows 密钥用当前系统账户的 DPAPI 加密保存，不包含在原始分发包中。拷贝到另一电脑后需要重新填写密钥。选择在线服务意味着相应文字/音频会发送到指定服务商，费用由服务商决定；没有密钥时不会自动调用。

内置 Qwen3-TTS CustomVoice 使用预设音色，**不是声音克隆模型**。克隆需先导入完整 Qwen3-TTS Base 权重文件夹，选择 Base 模型和克隆模式，再导入参考录音并填写逐字文本。

## 自己修改

`app/` 是自己的连接层和页面；`desktop/` 源码保留在开发工作区，包内桌面入口源码在 `resources/app/`；`sources/` 保留官方及加速项目源码与许可证；`models/` 为权重；`config/local.json` 为配置；`logs/` 为日志。详细结构见 `docs/开发说明.md`。

当前不包含直播弹幕、礼物或推流接入。商用/公开直播请单独确认代码、模型权重、人物及声音素材的使用授权。
