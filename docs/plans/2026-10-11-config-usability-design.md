# 配置交互预览版

用户授权直接实施，不构建整合包、ZIP或SHA256。源码预览版运行真实本地服务。

人物删除：已导入且非当前使用的形象可删除，二次确认；保留默认备用形象。API严格校验目录，禁止目录外路径。

音色三选一：本地CustomVoice预设、本地Base克隆、在线TTS。切换后只显示对应字段，参考录音仅克隆显示。与模型页运行方式双向同步。试听使用已保存配置，播放/暂停可切换，配置改变释放旧音频。

设备：真实enumerateDevices，未授权明确显示匿名提示。授权并刷新按钮立即关闭获取的媒体流，不持续录音。

对话模型：本地只展示GGUF及本地参数；在线只展示服务快捷设置、URL、API Key、模型选择。获取/models列表使用当前输入，不保存或日志输出密钥。无法枚举时保留手动填写接入点。语音接口保持条件显示。

验证：实际Electron预览界面、条件显示、删除保护/确认、模型列表模拟接口、播放暂停、配置持久化及真实本地音视频回归。供应商真实调用需用户密钥。
