# Windows 数字人工作台

用户目标：解压后双击 Windows EXE，自动启动服务；日常调整通过界面完成，源码、人物和模型可继续修改。

采用原生 Windows Electron + 便携 Python + llama.cpp，优先移除 WSL 依赖。相比继续包装 WSL，它更适合搬到另一台 Windows 电脑；相比只做浏览器启动器，它能统一管理服务、导入素材和本地权限。NVIDIA 驱动和足够显存仍是硬件前提，不能随包虚构。

界面：深灰工作台、暖白卡片、青绿状态。固定左栏三个菜单。控制台保持人物在左、聊天在右，增加运行状态与启动/停止/重启。数字人配置分形象库、声音、人设、互动四块；模型配置按 LLM / ASR / TTS / 口型 / 素材制作分别展开，展示已支持接口和真实能力。

形象：已有预处理人物可立即切换；视频导入先作为素材，必须预处理后才能驱动口型。动作来自连续视频，Wav2Lip 负责嘴部而非全身动画；静态照片不会自动变成动态底片。ComfyUI/Wan2.2 是可选外部素材工具，不放入每次对话的服务链，也不假装已经内置巨型模型。

服务：LLM 支持本地 llama.cpp 和 OpenAI 兼容在线 API（DeepSeek、豆包 Ark 的兼容端点）。ASR 支持本地 Faster Whisper、OpenAI 兼容转写。TTS 支持本地 Qwen3 CustomVoice、Base 声音克隆（需 Base 权重和参考录音）、OpenAI 兼容语音接口。口型当前支持本地 Wav2Lip256，仅列出确实可启动的引擎。在线接口需要用户提供密钥，测试由用户明确点击；密钥不回传、不写日志、分发包排除个人配置。

配置：保存前类型与范围校验。人设、在线 API、VAD 可以立即生效；本地权重、设备、口型批量需重启。保留最近一次有效配置，错误显示服务原因。导入路径由桌面文件选择器或受限上传处理，API 只监听本机。

验收：静态检查；配置保存与校验、重启生效；CPU/GPU 原生导入；浏览器与 Electron 真实 WebRTC、音频、帧差运动；便携目录换路径后启动。无密钥的在线服务只验证适配器，不宣称提供商已测试。物理麦克风仍需用户亲自确认。
