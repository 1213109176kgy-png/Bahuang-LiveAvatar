# Windows 源码开发

公开源码不包含巨型权重和运行时。建议先下载同版本整合包并完成首次口型模型导入，验证可运行。

1. 把整合包 `runtime/`、`models/`、`sources/LiveTalking/data/avatars/` 和导入的 `sources/LiveTalking/models/wav2lip.pth` 复制到源码对应目录。
2. 将包内干净 `config/local.json` 复制到源码目录，不复制个人 credentials 文件。
3. 源码根目录运行 `npm install --no-save electron@41.10.7`，再运行 `npx electron desktop`。

Python 环境优先复用嵌入运行时；重建依赖参照 setup/requirements-windows-lock.txt 与上游要求。

自有页面在 app/static/；桌面启动在 desktop/；上游版本见 setup/sources.json。界面修改后刷新，后端修改后重启。接口详见 [开发说明](开发说明.md)，发布过程见 [发布说明](发布说明.md)。
