选择已有形象，或上传自己的动态底片。

什么样的底片适合互动？1–30 秒、单人正面、固定镜头、嘴巴闭合。保留呼吸、眨眼和轻微身体动作。导入后会自动转为 25 帧并预处理口型。

更多音色 / 导入模型

预设音色内置在 CustomVoice 模型中，不是可以单独导入的录音文件。替换完整兼容模型后，下拉列表读取其预设音色；换成 1.7B 版本不代表一定增加音色。

官方预设模型下载 · Base 克隆模型下载

千问官网的 Flash / Flash-Realtime 音色列表属于云端服务，不能作为独立音色包下载到本地。当前开源 CustomVoice 模型自带 9 种预设。

预设音色直接可用。声音克隆需要 Base 模型和参考录音；当前内置 CustomVoice 权重不支持克隆。

底片制作 · 外部工具说明仅检测连接 · 尚未自动提交任务

可以用外部 ComfyUI + Wan2.2 制作人物动态视频，再从“数字人配置”导入。整合包不附带 Wan2.2 大型权重，也不会把尚未安装的工具显示成可用。

这个地址目前做什么？仅向原生 ComfyUI 请求 /system_stats 来检测连接。连接成功后，仍需在 ComfyUI 中运行工作流、导出 MP4，再到数字人配置添加人物底片；工作台不会自动提交生成任务。

本机一般填 http://127.0.0.1:8188；远程填写可访问的原生 ComfyUI 服务地址，不能填网页、工作流分享链接或 RunningHub 首页。

使用 RunningHub：在 RunningHub 网页运行工作流 → 下载 MP4 → 在本工作台添加底片。这里无需填写 RunningHub 地址。自动接入需单独的 API Key、工作流 ID、节点参数和任务查询接口，当前尚未接入。
